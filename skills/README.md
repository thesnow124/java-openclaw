# java-openclaw-lite 技能指南

## 📚 技能系统说明

java-openclaw-lite 使用技能系统来扩展 AI 的能力。技能是存储在 `skills/` 目录下的 Markdown 文件，描述了特定的行为模式、工作流程或专业知识。

## 🎯 技能的作用

当 AI 接收到用户请求时，System Prompt 会指示它：
1. **扫描可用技能** - 检查是否有相关技能
2. **读取技能文档** - 使用 `read_file` 工具读取 SKILL.md
3. **遵循技能指导** - 按照文档中的流程执行

这确保了 AI 能够：
- 使用最佳实践处理常见任务
- 保持一致的行为模式
- 逐步引导完成复杂任务
- 遵循团队约定的规范

## 📝 技能文件格式

每个技能必须包含：

### 前置元数据 (YAML Frontmatter)

```yaml
---
name: 技能名称
description: 简短描述技能的作用
emoji: 🎯  # 可选：技能图标
metadata:  # 可选：高级元数据
  openclaw:
    requires:
      bins: [工具1, 工具2]  # 需要的命令行工具
      env: [ENV_VAR]         # 需要的环境变量
    install:                 # 安装指引
      - id: brew
        kind: brew
        formula: tool-name
        label: 安装说明
---
```

### 技能内容

```markdown
# 技能标题

技能的详细描述。

## 触发时机
- 场景 1
- 场景 2

## 使用流程
1. 步骤一
2. 步骤二

## 输出格式
描述期望的输出格式

## 注意事项
- 注意点 1
- 注意点 2
```

## 🌐 如何翻译技能

### 方法一：使用 AI 翻译（推荐）

1. 读取原技能文件：
```json
{
  "tool": "read_file",
  "path": "skills/github/SKILL.md"
}
```

2. 请求 AI 翻译：
```
请将这个技能文件翻译为中文，保持：
- YAML frontmatter 不变（或翻译 description/label）
- 标题、说明、示例都翻译为中文
- 代码注释翻译为中文
- 命令和代码保持原样
```

### 方法二：手动翻译

1. 复制原技能文件
2. 翻译内容部分
3. 保持 YAML frontmatter 中的结构字段
4. 测试翻译后的技能

## 🚀 创建新技能

### 步骤

1. **创建目录**
```bash
mkdir -p skills/新技能名称
```

2. **创建 SKILL.md**
```bash
touch skills/新技能名称/SKILL.md
```

3. **编写内容**
使用上面的格式编写技能文档

4. **测试技能**
重启应用后，AI 会自动加载新技能：
```bash
pkill -f "spring-boot:run"
mvn spring-boot:run
```

## 🔍 技能调试

### 查看已加载的技能
```json
{
  "tool": "skills_status"
}
```

### 检查技能是否生效

1. 启动应用
2. 发送符合触发条件的请求
3. 观察 AI 是否读取了技能文档
4. 验证 AI 是否遵循技能指导

### 常见问题

**技能没有被加载**：
- 检查 SKILL.md 文件是否在技能目录下
- 检查 YAML frontmatter 格式是否正确
- 查看启动日志是否有错误

**AI 没有遵循技能**：
- 检查触发时机描述是否清晰
- 确认技能描述是否准确
- 尝试更明确的触发短语

**技能冲突**：
- 确保技能名称唯一
- 检查触发条件是否重叠
- 调整技能优先级（描述的具体程度）

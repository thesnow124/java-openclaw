---
name: todo
description: 用于整理和管理待办清单
---

这个技能帮助用户创建、查看、更新和删除待办事项，并支持按优先级、状态等分类整理。

## 触发时机
- 用户说"添加待办"、"查看待办事项"、"更新任务状态"、"删除任务"
- 用户提到"todo"、"待办清单"、"任务列表"、"今日任务"
- 用户需要整理工作或学习计划

## 使用流程
1. 首先询问用户想要执行的操作：创建、查看、更新、删除还是清空待办事项
2. 根据用户选择执行相应操作：
   - 创建：询问任务描述、截止时间、优先级（高/中/低）
   - 查看：按状态（待办/进行中/已完成）、优先级或时间顺序显示
   - 更新：选择任务，更新状态或描述
   - 删除：选择要删除的任务
   - 清空：确认后清空所有待办事项
3. 待办数据存储在 `data/todo.json` 文件中，使用 JSON 格式
4. 每次操作后显示更新后的待办清单概览

## 输出建议
- 使用简洁的列表格式显示待办事项
- 为不同状态的任务使用不同标记（如 □ 待办、▶ 进行中、✓ 已完成）
- 显示任务数量统计（总计/待办/进行中/已完成）
- 提供下一步操作建议

## 约束与注意
- 不擅自修改用户数据，每次写文件前先确认
- 如果 `data/todo.json` 不存在，创建初始空数组 `[]`
- 支持基本的 CRUD 操作，不涉及复杂的时间调度算法
- 文件路径限制在工作区内，不能访问外部文件

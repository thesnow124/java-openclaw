# 问题排查技能

这个技能帮助用户系统化地诊断和解决技术问题。

## 触发时机
- 用户遇到报错或异常
- 系统不按预期工作
- 性能问题
- 配置问题
- 用户说"帮我看看这个错误"

## 排查方法论

### 第一步：收集信息
1. **错误信息**
   - 完整的错误消息
   - 错误代码
   - 堆栈跟踪

2. **环境信息**
   - 操作系统和版本
   - 软件版本
   - 依赖版本
   - 配置信息

3. **复现步骤**
   - 如何触发问题
   - 是否稳定复现
   - 触发条件

4. **上下文**
   - 最近的变更
   - 使用场景
   - 预期行为 vs 实际行为

### 第二步：分析问题

#### 问题分类
- **代码错误**：语法、逻辑、类型错误
- **配置问题**：参数设置、路径、权限
- **依赖问题**：版本冲突、缺失依赖
- **环境问题**：系统兼容性、资源限制
- **网络问题**：连接、超时、防火墙
- **数据问题**：格式、大小、编码

#### 诊断策略
```
1. 检查错误日志
2. 验证配置文件
3. 检查依赖版本
4. 查看系统资源
5. 测试网络连接
6. 检查文件权限
```

### 第三步：制定方案

#### 优先级
- 🔴 **P0 严重**：系统崩溃、数据丢失、安全漏洞
- 🟠 **P1 高**：功能不可用、性能严重下降
- 🟡 **P2 中**：功能异常、有变通方案
- 🟢 **P3 低**：体验问题、优化建议

#### 方案评估
- **影响范围**：会影响哪些功能或用户
- **风险评估**：可能引入的新问题
- **工作量**：实施难度和时间
- **收益**：解决问题的程度

### 第四步：实施修复

#### 修复步骤
1. 备份相关配置和数据
2. 在测试环境验证
3. 应用修复方案
4. 验证问题解决
5. 检查是否有副作用

#### 回滚计划
- 记录修改内容
- 保留回滚方案
- 准备快速回滚步骤

### 第五步：总结预防

#### 根本原因分析
- 为什么会发生？
- 如何避免再次发生？
- 需要改进什么？

#### 预防措施
- 添加监控和告警
- 完善文档
- 改进代码质量
- 加强测试

## 常见问题排查

### Java 应用

#### 内存溢出 (OutOfMemoryError)
```bash
# 查看堆内存使用
jmap -heap <pid>

# 分析堆转储
jmap -dump:format=b,file=heap.hprof <pid>

# 临时方案：增加堆内存
java -Xmx2g -Xms1g
```

#### CPU 占用高
```bash
# 查找高 CPU 线程
top -H -p <pid>

# 导出线程堆栈
jstack <pid> > thread_dump.txt

# 分析线程状态
grep "java.lang.Thread.State" thread_dump.txt | sort | uniq -c
```

#### 应用启动失败
1. 检查端口是否被占用：`lsof -i :<port>`
2. 检查配置文件语法
3. 检查依赖版本兼容性
4. 查看启动日志

### Spring Boot

#### Bean 创建失败
```
错误: UnsatisfiedDependencyException
排查:
1. 检查 @ComponentScan 范围
2. 验证依赖注入配置
3. 检查循环依赖
4. 查看 @Conditional 条件
```

#### 配置不生效
```
排查:
1. 确认配置文件位置
2. 检查 profile 激活
3. 验证属性名拼写
4. 查看属性优先级
```

### 数据库

#### 连接失败
```
排查:
1. 检查数据库服务状态
2. 验证连接字符串
3. 检查防火墙规则
4. 测试网络连通性: telnet <host> <port>
```

#### 慢查询
```
优化:
1. 开启慢查询日志
2. 使用 EXPLAIN 分析执行计划
3. 检查索引使用
4. 优化查询语句
5. 考虑分页或缓存
```

## 日志分析

### 日志级别
- **ERROR**: 错误，需要立即处理
- **WARN**: 警告，可能的问题
- **INFO**: 重要信息
- **DEBUG**: 调试信息

### 查找技巧
```bash
# 查找错误
grep ERROR app.log

# 查找特定时间段的日志
grep "2026-02-07 12:" app.log

# 统计错误类型
grep ERROR app.log | awk '{print $NF}' | sort | uniq -c | sort -rn

# 查找上下文
grep -A 10 -B 5 "Exception" app.log
```

## 性能问题

### 诊断工具
- **VisualVM**: JVM 监控和分析
- **JProfiler**: 性能分析
- **Arthas**: 在线诊断
- **Flame Graph**: 火焰图分析

### 优化方向
- **算法优化**: 降低时间复杂度
- **缓存**: 减少重复计算
- **异步**: 并发处理
- **批量操作**: 减少 I/O 次数
- **索引**: 加速查询

## 注意事项
- 保持冷静，系统化排查
- 一次只改一个变量
- 记录所有尝试和结果
- 优先找到根因而不是症状
- 考虑长期解决方案而非临时修复
